# 👩‍💻 Portfólio Profissional - Ana Júlia Firmiano

Website de portfólio pessoal e profissional com foco em **Engenharia de Dados & Desenvolvimento Web**.

Desenvolvido com uma interface moderna, dinâmica e responsiva, alimentada por dados estruturados em JSON.

---

## ✨ Recursos

- **Perfil Dinâmico:** Apresentação profissional, biografia, stack tecnológica e métricas.
- **Catálogo de Habilidades:** Organizado por áreas de atuação (Dados, DevOps, Analytics, Web).
- **Galeria de Projetos:** Exibição interativa de projetos em ETL, automação, Python, Pandas e desenvolvimento frontend.
- **Carregamento Assíncrono:** Os dados de perfil, projetos e habilidades são consumidos dinamicamente de `data.json` através do `script.js`.
- **Design Responsivo & Estilizado:** Tipografia com *Plus Jakarta Sans* e *JetBrains Mono*, efeitos de glow, pixel art e paleta moderna.

---

## 📁 Estrutura do Projeto

```text
portifolio/
├── index.html       # Estrutura e semântica do website
├── style.css        # Estilos, variáveis CSS, layout flex/grid e animações
├── script.js        # Lógica de renderização dinâmica via Fetch API
├── data.json        # Dados estruturados de perfil, habilidades, projetos e redes
├── pixel.png        # Ilustração em Pixel Art
├── .gitignore       # Arquivos ignorados pelo Git
└── README.md        # Documentação do repositório
```

---

## 🚀 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web moderno (ou utilizando a extensão Live Server no VS Code).

```bash
# Clonar o repositório
git clone https://github.com/anajufirmiano/portifolio.git

# Acessar a pasta
cd portifolio
```
